### 👋 About me

I'm a computer science student at **GM University** working at the intersection of **cybersecurity** and **applied AI**. I like understanding how systems break, and then building software that doesn't.

- 🔐 **Focus:** web application security, authentication & API hardening, OWASP Top 10, secure code review
- 🤖 **Building:** AI products that real people use, from campus assistants to ML-driven analysis tools
- 🧪 **Shipping daily:** a new browser-based security or AI tool in my [Security & AI Lab](https://nethrapalmjali.github.io/security-ai-lab/)
- 🤝 **Open to:** internships, security research collaborations, and hackathon teams
